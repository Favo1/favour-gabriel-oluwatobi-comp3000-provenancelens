# Data

No project dataset has been selected or downloaded at project initiation. This directory is reserved for dataset documentation and small manifest files.

- `manifests/`: CSV manifests should record image identifier/path, label, generator or source, licence and checksum.
- Raw, processed and generated images should remain local or in approved external storage and must not be committed to Git.

Before downloading or generating data, check the applicable terms and record the source and licence in [docs/data-sources.md](../docs/data-sources.md). Download and preprocessing scripts are planned backlog work and are not yet implemented.
