# Project vision

**For** journalists, fact-checkers and everyday social-media users who need to assess the authenticity of digital images, **ProvenanceLens** is a deep-learning image-forensics project that will investigate whether an image is authentic, fully AI-generated or locally edited using generative AI. It will evaluate generalisation to generators not represented during training and explore calibrated confidence and visual explanations.

**Research question:** Which image features and training strategies allow an image detector to remain accurate when the generative model changes?

**Keywords:** AI-generated image detection; AI image editing; image forensics; deep learning; generator generalisation; robustness; confidence calibration; explainability.

## Initial aims

1. Establish a reproducible benchmark of real, AI-generated and AI-edited images, subject to data availability and licensing.
2. Implement and compare suitable CNN, Vision Transformer and frozen-CLIP approaches against a published baseline.
3. Evaluate unseen-generator generalisation, robustness to common image transformations and confidence calibration.
4. Investigate visual explanations. Edited-region localisation and a demo application are stretch objectives.

## Scope and status

This is the Sprint 0 working vision. The project title, methods and scope may be refined with the supervisor as the literature review and feasibility work progress. No dataset or model has yet been selected as a final project dependency.
