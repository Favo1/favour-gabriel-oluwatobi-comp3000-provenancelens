# Project initiation submission checklist

Based on the COMP3000 2026–27 assessment brief, Phase 2 Project Initiation requires the ePortfolio section to contain a project title, keywords, project vision, literature review, risk assessment and Gantt chart. The repository should also identify the project title, vision and allocated supervisor in its README, and the supervisor must be given repository access.

- [x] Working project vision and research question included.
- [x] Initial keywords recorded.
- [x] Supervisor named as Dr Vivek Singh in README (verify this matches the final allocation).
- [x] Initial risk register completed, including mitigations for high/high risks.
- [x] Relative high-level sprint plan added in `gantt.md`.
- [x] Initial architecture and technology decisions documented.
- [x] Data-source and third-party licensing register explains that no dataset/model/code source has yet been selected.
- [x] Proposed Creative Commons licence notice and scope/exclusions documented.
- [x] AI assistance recorded in `ai-use-log.md`.
- [x] Duplicate README content removed and setup instructions corrected.
- [x] Starter test suite passes locally (4 tests).
