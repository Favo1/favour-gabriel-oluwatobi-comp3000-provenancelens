# Licensing and third-party materials

## Proposed licence for original project materials

The proposed licence for original materials in this repository is **Creative Commons Attribution 4.0 International (CC BY 4.0)**. This is intended to meet the COMP3000 brief's request for a Creative Commons licence. The student must confirm this choice with the project supervisor before relying on it as the final project licence.

The licence permits sharing and adaptation with appropriate attribution. The full legal code is available at: <https://creativecommons.org/licenses/by/4.0/legalcode>. A human-readable summary is available at: <https://creativecommons.org/licenses/by/4.0/>.

## Scope and exclusions

- The proposed licence applies only to original material created for this project and owned by the student, subject to confirmation with the supervisor.
- Third-party datasets, pretrained model weights, libraries, source code, images, fonts and other assets are **not** relicensed by this repository notice. Their original terms continue to apply.
- Do not add third-party material unless its licence and intended use have been checked and recorded in [data-sources.md](data-sources.md).
- If a third-party licence conflicts with the proposed project licence, keep the material separate, comply with its own terms, and ask the supervisor for guidance.
- The CC BY 4.0 licence is not a software-specific licence and does not provide an express patent grant. If the project later distributes substantial software as a reusable product, discuss whether a separate software licence is appropriate with the supervisor.
