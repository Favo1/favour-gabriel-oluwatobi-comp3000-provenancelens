# Initial high-level project plan

This is a **relative sprint plan**, not a calendar-dated commitment. The COMP3000 brief expects a high-level plan and a living backlog. Each sprint is planned around the fortnightly supervisory cycle; confirm exact dates and adjust the plan with the supervisor.

| Work package | Main activities / outputs | Planned sprint window |
|---|---|---|
| WP1 – Initiation and project setup | Confirm vision, environment, repository, CI, backlog, risks and project plan | S0–S1 |
| WP2 – Literature review and methodology | Review image forensics and detection research; select research question, baseline and evaluation protocol | S1–S3 |
| WP3 – Data and benchmark | Select licensed data sources, build manifests and preprocessing, define generator-aware splits | S1–S4 |
| WP4 – Baseline implementation | Implement initial CNN baseline and evaluation harness | S2–S5 |
| WP5 – Comparative experiments | Reproduce a published baseline; implement CLIP/ViT comparisons; unseen-generator and robustness experiments | S5–S9 |
| WP6 – Explainability and calibration | Confidence calibration and visual explanations; localisation only if feasible | S8–S10 |
| WP7 – Analysis and evaluation | Ablations, failure analysis, interpretation and conclusions | S9–S11 |
| WP8 – Showcase materials | Poster and project description, incorporating supervisor feedback | S8–S10 |
| WP9 – Optional demo | Small demonstration application if core objectives are on schedule | S10–S12 |
| WP10 – Report and portfolio | Draft, revise and complete report and ePortfolio evidence | S2–S13 |
| WP11 – Final preparation | Video demo, final repository checks, submission and viva preparation | S12–S13 |
